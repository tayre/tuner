# String

A precise, privacy-friendly browser guitar tuner. It uses the Web Audio API and a YIN-style pitch detector to tune from a built-in, USB, or webcam microphone without uploading audio.

## Deploy to Cloudflare Pages

- **Root directory:** *(leave blank)*
- **Build command:** *(leave blank)*
- **Build output directory:** `.`

The page is plain HTML, CSS, and JavaScript—no install or build step is needed.

Microphone access requires HTTPS or localhost. Cloudflare Pages provides HTTPS automatically.
